Install

One command. The installer finds Python 3.10+, builds an isolated environment in ~/.walletcli/venv, and links wallet onto your PATH.

install
$ git clone <repo> && cd wallet-management && ./install.sh
✔ Using Python 3.12 · ✔ Installed walletcli 1.0.0 · ✔ Linked ~/.local/bin/wallet

# remove the tool (never touches your vault):
$ ./install.sh --uninstall

Quickstart

first five minutes
$ wallet register          # create or import a wallet — guided
$ wallet balance           # six assets, one table
$ wallet send              # transfer with fee preview + review screen
$ wallet swap              # USDT-ERC20 ⇄ USDT-TRC20 and friends
$ wallet                   # overview of everything below
Every command is interactive. Run it with no flags and follow the prompts — flags exist so the same command can be scripted. --help works everywhere.

Commands

$ wallet

With no arguments: vault status and a table of every command. --version/-V prints the version.

$ wallet register

Create a new wallet (fresh BIP39 phrase) or import an existing 12–24-word phrase. One mnemonic derives both accounts — Ethereum (m/44'/60'/0'/0/0) and Tron (m/44'/195'/0'/0/0) — then everything is encrypted into the vault under your passphrase.

OptionDescription
--name, -nWallet name (letters, digits, . _ -, max 32 chars)
--wordsPhrase length for new wallets: 12 / 15 / 18 / 21 / 24 (default 24)
--mnemonicImport this phrase non-interactively CAREFUL — shell history
--yes, -ySkip the written-backup verification quiz

Hidden import: when importing, the phrase is typed or pasted with echo disabled — nothing appears on screen or in terminal scrollback. The BIP39 checksum is validated before anything is stored, and you're re-prompted on a typo.
An optional BIP39 passphrase ("25th word") can be added in the advanced step — it changes every derived address and becomes part of your backup.

$ wallet swap

Cross-chain swap (ERC20 ⇄ TRC20) through ChangeNOW, a non-custodial instant exchange. You get a quote, a one-time deposit address is created, walletcli can send the deposit for you, and the payout lands on your own address on the destination chain — tracked live. Requires a free API key: wallet config set changenow_api_key <key>.

OptionDescription
--wallet, -wWallet to swap with
--from, -fAsset to swap from, e.g. usdt-erc20
--to, -tAsset to receive, e.g. usdt-trc20 (must be the other chain)
--amount, -mAmount to swap
--yes, -ySkip confirmations (auto-sends the deposit)

$ wallet swap-status ORDER_ID

Check a swap order once, or follow it with --watch until it completes. Useful after pressing Ctrl-C during a swap — orders keep processing server-side.

OptionDescription
--watchPoll every 8 s until finished / failed (45 min cap)

$ wallet address add | list | remove

Address book: save recipient addresses under human aliases and use the alias anywhere an address is asked — including wallet send --to mom and the interactive recipient picker. The network is detected automatically from the address format, and sending an asset to an alias on the wrong chain is blocked with a clear error. After a successful send to a new address, walletcli offers to save it. Stored in ~/.walletcli/addressbook.json.

SubcommandDescription
add [ALIAS] [ADDRESS]Save a contact (interactive when arguments are omitted)
listAll contacts: alias, network, full address, date added
remove ALIAS [--yes]Delete a contact (asks first)

$ wallet export [NAME]

Reveal a wallet's recovery phrase after passphrase verification — for restoring into MetaMask, TronLink, or a hardware wallet. Warns first; make sure no one can see your screen.

$ wallet remove [NAME]

Delete a wallet's encrypted entry from the vault. Funds stay on-chain — but without a written backup of the phrase they become unreachable, so the command makes you type the wallet's name to confirm (--yes/-y skips).

Security

Secrets are sealed per wallet with AES-256-GCM under a key derived by Argon2id (3 iterations · 128 MiB · 4 lanes). The passphrase is never stored; entries are cryptographically bound to their wallet names, so tampering and blob-swapping are detected. Vault files are written atomically with 0600 permissions. A stolen vault file is computationally useless without the passphrase.

Honest limits: no software wallet can defend an actively compromised machine — a keylogger captures passphrases as they're typed. For significant funds, use a hardware wallet, and keep the recovery phrase on paper only.
